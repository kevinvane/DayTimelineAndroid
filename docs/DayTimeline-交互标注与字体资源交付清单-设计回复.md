# DayTimeline-交互标注与字体资源交付清单（给研发）

下面把 **M0-2 交互标注** 与 **M0-3 切图与字体资源** 按蓝色系 DayTimeline 定稿补齐。  
原则不变：**不改名、不新增常驻子 View、不引入第三方依赖、热区 ≥ 48dp、深浅色只靠资源替换、组件不写死字面量。**

> 本交付与 M0-1 蓝色系色值配套使用。  
> 蓝色系关键值：  
> - 浅色强调：`#2F6FED` / `#1D5FD6` / `#2A66E0`  
> - 深色提亮：`#8AB8FF` / `#A8CBFF`  
> - 当前时间线：`#D92D20` / `#FF8A80`  
> - 编辑层底色：`#66FFFFFF` / `#66101318`

# M0-2 交互标注交付

## 1. 交互状态流转图

### 1.1 状态定义

| 状态 | 名称 | 说明 |
|---|---|---|
| S0 | 浏览态 | 默认态，可点击、长按日程块 |
| S1 | 新建编辑态 | 点击空白区域进入，默认时长 1 小时 |
| S2 | 编辑态 | 长按日程块进入，可移动 / 改时长 |

## 2. 切图 / 图标资源

### 2.1 现状判定

组件当前不消费任何位图或矢量图资源：

- 无 `R.drawable`
- 无 `R.font`
- 无 `Typeface` 引用
- 左侧色条、当前时间圆点与线、上下编辑手柄全部 Canvas 自绘

### 2.2 设计判定

**本次判定为「无位图需求」。**

理由：

1. 蓝色系色值已能完整表达日程块、色条、当前时间线、编辑手柄。
2. 引入图标会触及 §12.1「网格区常驻界面元素数 = 0」。
3. 引入 `ImageView` 会被 `:library:verifyNoChildViews` 门禁拦下。
4. K10 要求运行时零第三方依赖，图标库不可引入。

因此本子项关闭，组件维持全自绘。

### 2.3 若后续要引入图标

必须满足：

- 不以子 View 承载，必须以 Canvas / Drawable 自绘方式合入；
- 不引入第三方图标库；
- 提供多倍图或 VectorDrawable；
- 命名与颜色说明，是否随主题色着色；
- 深浅色两套资源，不允许代码分支。
